# glyph-morph

Text that changes in one wave across its letters. Letters both strings share blur, slide up and swap. Extra letters of a longer string write on with a glow. Extra letters of a shorter string backspace from the end. The wave runs left to right as the text grows and right to left as it shrinks.

| Platform | Package | Folder |
| --- | --- | --- |
| Flutter | `glyph_morph` | [`flutter/`](flutter) |
| Web: vanilla JS, custom element, React | `glyph-morph` | [`web/`](web) |

Both versions use the same timings and keyframes. With reduce motion on, the text swaps at once.
